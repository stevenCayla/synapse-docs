---
title: "Cas d'usage EDC par profil (Step-by-step)"
---

## 1. Super Admin / Admin sponsor

### Créer une étude

1.  Se connecter
2.  Accéder au module Études
3.  Créer une étude
4.  Renseigner infos (titre, protocole, promoteur...)
5.  Définir paramètres
6.  Enregistrer
7.  Vérifier présence + audit trail

### Ajouter des sites

1.  Ouvrir étude
2.  Onglet Sites
3.  Ajouter site
4.  Renseigner infos
5.  Sauvegarder

------------------------------------------------------------------------

## 2. Data Manager / Builder eCRF

### Construire un eCRF

1.  Ouvrir étude
2.  Aller au builder
3.  Ajouter sections/champs
4.  Configurer validations
5.  Sauvegarder
6.  Tester
7.  Publier version

### Versionner formulaire

1.  Ouvrir formulaire
2.  Créer nouvelle version
3.  Modifier
4.  Publier
5.  Vérifier anciennes données intactes

------------------------------------------------------------------------

## 3. Investigateur principal (PI)

### Consulter patients

1.  Ouvrir étude
2.  Voir patients du site
3.  Filtrer
4.  Ouvrir dossier

### Signer eCRF

1.  Vérifier données
2.  Cliquer signer
3.  Confirmer
4.  Vérifier audit trail

------------------------------------------------------------------------

## 4. Coordinateur / Site staff

### Inclure patient

1.  Ouvrir étude
2.  Choisir site
3.  Créer patient
4.  Renseigner infos
5.  Sauvegarder

### Saisir données

1.  Ouvrir patient
2.  Ouvrir visite
3.  Remplir eCRF
4.  Sauvegarder

------------------------------------------------------------------------

## 5. CRA / Moniteur

### Ouvrir query

1.  Ouvrir sujet
2.  Sélectionner champ
3.  Créer query
4.  Envoyer

### Fermer query

1.  Vérifier réponse
2.  Fermer ou rouvrir

------------------------------------------------------------------------

## 6. Biostatisticien

### Exporter données

1.  Ouvrir étude
2.  Choisir export
3.  Sélectionner format
4.  Télécharger

------------------------------------------------------------------------

## 7. QA / Audit

### Vérifier audit trail

1.  Ouvrir donnée
2.  Voir historique
3.  Vérifier old/new value

------------------------------------------------------------------------

## 8. Inspecteur

### Auditer sujet

1.  Accéder étude
2.  Ouvrir sujet
3.  Vérifier données + historique

------------------------------------------------------------------------

## Checklist globale

-   Inclusion patient (étude + site)
-   Audit trail complet
-   RBAC strict
-   Queries
-   Signature électronique
-   Export données
